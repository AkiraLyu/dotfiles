# 应用源码

这里只维护 `diary/` 的拾光日记源码。它的 PKGBUILD 在 [AkiraLyu/pkgbuilds](https://github.com/AkiraLyu/pkgbuilds/tree/main/shiguang-diary)，从本仓库的 GitHub 版本构建：

```sh
paru --sudo run0 -S shiguang-diary
```

KDE 插件、主题、补丁和设置统一在 [AkiraLyu/kde-plugins](https://github.com/AkiraLyu/kde-plugins)。
Gamescope、WPS FPS Unlock 和知乎导出器使用各自 GitHub 仓库，配方统一在 pkgbuilds；本目录不保留源码副本。
应用数据、日记库和导出数据不属于源码，也不由软件包清理。
